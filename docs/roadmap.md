# Development roadmap

1. Replace fictional records incrementally with sourced race editions. Build a validation and review workflow for each field, source, and verification date. Keep stale registration and price information clearly dated.
2. Make course intelligence a core part of each verified profile. Start with discovery of official route files and original source links, then render geographically accurate maps for verified, edition-specific geometry. Establish GPX catalog search by race, region, year, and download availability. Record redistribution rights before hosting any downloads.
3. Derive elevation profiles, gradient segments, significant climbs and descents, and terrain summaries from verified course versions. Document elevation data source, smoothing, and gradient thresholds. Keep old and current courses independently accessible.
4. Expand matching with more specific dates and geography, regional units and currency, and travel estimates from a runner's chosen origin. Test scoring and missing-data behavior as the verified catalog grows.
